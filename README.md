# Real Time Chat Application

Project of CS 699 course at IIT Bombay, Autumn 2022.

This is a real-time chat application developed as part of the Software Lab Course. The project enables users to communicate via text messages in individual chats with a user-friendly interface.


# Objective


The objective of this project is to develop a real-time chat application that facilitates seamless communication between users. It aims to provide a secure, efficient, and user-friendly platform for both individual messaging. This project is created as part of the Software Lab Course to enhance understanding of full-stack development, real-time data transmission, and user authentication mechanisms.
